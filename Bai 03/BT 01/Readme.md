
# BÀI 3 - BÀI TẬP 1

## 1. Nội dung bài tập
- Khai báo danh sách 5 sinh viên.
- Sử dụng class và constructor để biểu diễn sinh viên.
- Sử dụng Arrow Function để lọc sinh viên có điểm từ 5 trở lên.
- Hiển thị danh sách bằng console.log().

## 2. Công nghệ sử dụng
- Node.js
- JavaScript
- Visual Studio Code

## 3. Cách thực hiện

### Bước 1: Mở Terminal
Mở Terminal tại thư mục BT 01.
Sử dụng lệnh: 
cd "Bài 3 - Bài Tập 1\Node JS\Bai 03\BT 01"

### Bước 2: Chạy chương trình
Sử dụng lệnh:

node bai01.js

### Bước 3: Kết quả
Chương trình hiển thị danh sách 3 sinh viên
có điểm từ 5 trở lên.

## 4. Kết quả chạy chương trình
Chèn ảnh Terminal hiển thị kết quả chạy thành công tại đây.
